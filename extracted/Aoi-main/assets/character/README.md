# Character Sprites

Upload the cropped transparent PNG animation frames for the playable character into this folder.

Suggested filenames:
- idle_1.png through idle_4.png
- walk_1.png through walk_6.png
- jump_1.png, jump_2.png
- fall_1.png, fall_2.png
- punch_1.png through punch_4.png
- land_1.png, land_2.png

Keep each frame as a separate transparent PNG. Frame dimensions can be consistent across each animation; do not resize or crop away the character's feet/hands. The game integration will be updated after the frames are uploaded.
